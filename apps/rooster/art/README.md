# ROOSTER logo

A 3D wireframe of Pablo's geometric rooster: head, tail and body are extruded at different
depths, and the eye is a 75%-filled gauge.

- `logo.js` builds the logo as SVG with no dependencies: `roosterSVG({ size, ry, rx, bg, glow, mesh, lw, scale })`.
  The app uses the same code (inlined in `../index.html`) for the turning logo in its header.
- `rooster-app-icon-1024.png`: app store size. `rooster-transparent-1024.png`: no background.
- `../icon-180.png`, `../icon-192.png`, `../icon-512.png`: home screen and web app icons.
