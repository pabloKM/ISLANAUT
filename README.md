# ISLANAUT

Game and app prototypes by **PabloKM × Claude**. Every game lives in `games/<name>/` and every
app in `apps/<name>/`, and all of them run in the browser:

**▶ https://pablokm.github.io/ISLANAUT/**

Each push to `main` rebuilds the front page from the `game.json` and `app.json` files and publishes the
site through GitHub Pages (`.github/workflows/pages.yml`). See `CLAUDE.md` for the layout.
