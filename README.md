Game prototypes by **PabloKM × Claude**. Every game lives in `games/<name>/` and can be
played in the browser:

**▶ https://pablokm.github.io/ISLANAUT/**

site through GitHub Pages (`.github/workflows/pages.yml`). See `CLAUDE.md` for the layout.
